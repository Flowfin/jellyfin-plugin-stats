Where this plugin keeps its data

Under the server's data directory, in plugins/Jellyfin.Plugin.Stats, with the settings on this page saved beside it in plugins/configurations/Jellyfin.Plugin.Stats.xml.

Removing this plugin deletes both of them. If a deletion fails, the server log names the path that was left behind so it can be removed by hand.
